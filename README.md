# 기능 구현 목록

## 1. 입력
- [X] 자동차 이름이 적힌 문자열 입력
- [X] 경주 진행 횟수 n 입력

## 2. 출력
- [X] "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)" 출력
- [X] "시도할 횟수는 몇 회인가요?" 출력
- [] "실행 결과" 출력 이후 n회의 경주 기록 출력
- [] "최종 우승자 : " 출력 이후 최종 우승자 출력. 출력 시 우승자가 2명 이상이면 ","로 구분하여 출력

## 3. 검증
- [] 이름의 길이가 5보다 크면 예외
- [] 이름에 알파벳 대/소문자가 아닌 문자가 들어갔으면 예외

## 4. 문자열 분리 하여 저장
- [] 문자열을 "," 기준으로 분리하고, 검증
- [] 분리된 문자열을 이름으로 가지는 자동차 생성

## 5. 경주 진행
- [X] pickNumberInRange()로 경주 시 전진/멈춤 구분 
- [] 1회 경주 진행할 때마다 자동차들의 상태 업데이트
- [] 1회 경주 진행할 때마다 경주 기록 출력

## 6. 우승자 파악
- [] 자동차들 중 가장 멀리 간 자동차 파악
- [] 우승자 출력
